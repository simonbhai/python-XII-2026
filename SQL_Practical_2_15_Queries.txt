PART A — EXTRA COMMANDS REQUIRED TO CREATE AND FILL THE TABLES
--------------------------------------------------------------

1. Create and select the database
Usage: Creates the database and makes it the active database.

2. Create the INFO table
Usage: Creates the employee table with all eight columns, including CITY.

CREATE TABLE INFO (
    EMPID VARCHAR(10) PRIMARY KEY,
    NAME VARCHAR(30),
    GENDER CHAR(1),
    AGE INT,
    DESIGNATION VARCHAR(30),
    DOJ DATE,
    SALARY INT,
    CITY VARCHAR(30)
);

PART B — THE 15 QUESTIONS AND ANSWERS
-------------------------------------

1. Question: Write a query to list the names of employees in descending order.

Query:
SELECT NAME
FROM INFO
ORDER BY NAME DESC;

Usage: Lists employee names from Z to A.


2. Question: Write a query to display the maximum salary and minimum salary of employees.

Query:
SELECT MAX(SALARY) AS Maximum_Salary,
       MIN(SALARY) AS Minimum_Salary
FROM INFO;

Usage: MAX() returns the highest salary and MIN() returns the lowest salary.


3. Question: Write a query to count the number of employees earning more than 25000.

Query:
SELECT COUNT(*) AS Employee_Count
FROM INFO
WHERE SALARY > 25000;

Usage: Counts only employees whose salary is greater than 25000.


4. Question: Write a query to display designations where the number of employees is greater than or equal to 2.

Query:
SELECT DESIGNATION, COUNT(*) AS Employee_Count
FROM INFO
GROUP BY DESIGNATION
HAVING COUNT(*) >= 2;

Usage: GROUP BY groups employees by designation; HAVING filters groups by their employee count.


5. Question: Write a query to display the sum of salary of employees, grouped designation-wise.

Query:
SELECT DESIGNATION, SUM(SALARY) AS Total_Salary
FROM INFO
GROUP BY DESIGNATION;

Usage: Adds the salaries of employees within each designation.


6. Question: Display the names of various cities from INFO, with each city appearing only once.

Query:
SELECT DISTINCT CITY
FROM INFO;

Usage: DISTINCT removes duplicate city names.


7. Question: Display the details of all employees whose salary is between 25000 and 33000.

Query:
SELECT *
FROM INFO
WHERE SALARY BETWEEN 25000 AND 33000;

Usage: BETWEEN includes both boundary values, 25000 and 33000.


8. Question: Display the name and salary of employees whose salary is above 30000 and whose gender is not male.

Query:
SELECT NAME, SALARY
FROM INFO
WHERE SALARY > 30000
  AND GENDER <> 'M';

Usage: Displays name and salary for employees earning above 30000 who are not marked M.


9. Question: Write a query to find the average salary of all employees. [The handwriting appears to ask for the average salary.]

Query:
SELECT AVG(SALARY) AS Average_Salary
FROM INFO;

Usage: AVG() calculates the average of all salary values.


10. Question: Display the maximum salary of employees in each designation.

Query:
SELECT DESIGNATION, MAX(SALARY) AS Maximum_Salary
FROM INFO
GROUP BY DESIGNATION;

Usage: Shows the highest salary within each designation.


11. Question: Display the name and respective department name of each employee whose salary is more than 30000. [The salary limit is unclear in the photo; 30000 is assumed.]

Query:
SELECT INFO.NAME, DEPT.DEPTNAME
FROM INFO
INNER JOIN DEPT ON INFO.EMPID = DEPT.EMPID
WHERE INFO.SALARY > 30000;

Usage: JOIN matches employee and department rows using EMPID, then filters by salary.


12. Question: Display name and designation from INFO, and department name and floor number from DEPT.

Query:
SELECT INFO.NAME, INFO.DESIGNATION, DEPT.DEPTNAME, DEPT.FLOORNO
FROM INFO
INNER JOIN DEPT ON INFO.EMPID = DEPT.EMPID;

Usage: Joins the two tables and displays the requested columns.


13. Question: Display department name and sum of salary, grouped designation-wise, from INFO and DEPT, in ascending order of salary sum.

Query:
SELECT DEPT.DEPTNAME, SUM(INFO.SALARY) AS Total_Salary
FROM INFO
INNER JOIN DEPT ON INFO.EMPID = DEPT.EMPID
GROUP BY DEPT.DEPTNAME
ORDER BY Total_Salary ASC;

Usage: Joins the tables, totals salaries for each department name, and sorts totals from low to high.
Note: The notebook wording seems to mix “group by designation” with “department name”. This query groups by department name because that is the displayed output requested.


14. Question: Display the number of employees in table INFO.

Query:
SELECT COUNT(*) AS Number_of_Employees
FROM INFO;

Usage: Counts all rows in INFO.


15. Question: Display the maximum salary of male employees from INFO.

Query:
SELECT MAX(SALARY) AS Maximum_Male_Salary
FROM INFO
WHERE GENDER = 'M';

Usage: Filters for male employees first, then returns their highest salary.
