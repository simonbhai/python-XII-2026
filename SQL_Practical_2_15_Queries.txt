```sql
CREATE TABLE Employee (

    Name VARCHAR(30),
    Gender VARCHAR(10),
    Age INT,
    Designation VARCHAR(30),
    DOJ DATE,
    Salary DECIMAL(10,2),
    City VARCHAR(30)
);
```

Question 1: Write a query to list the names of employees in descending order.

SELECT Name
FROM Employee
ORDER BY Name DESC;

Question 2: Write a query to display the maximum salary and minimum salary of employees.
SELECT
    MAX(Salary) AS Maximum_Salary,
    MIN(Salary) AS Minimum_Salary
FROM Employee;


Question 3: Write a query to count the number of employees earning more than 25,000.
SELECT COUNT(*) AS Employee_Count
FROM Employee
WHERE Salary > 25000;

Question 4: Write a query to display the designations where the number of employees is greater than or equal to 2.
SELECT Designation, COUNT(*) AS Employee_Count
FROM Employee
GROUP BY Designation
HAVING COUNT(*) >= 2;

Question 5: Write a query to display the sum of salaries of employees, grouped by designation.
SELECT Designation, SUM(Salary) AS Total_Salary
FROM Employee
GROUP BY Designation;

Question 6: Write a query to display the names of different cities from the Employee table, with each city appearing only once.
SELECT DISTINCT City
FROM Employee;

Question 7: Write a query to display the details of all employees whose salary is between 25,000 and 33,000.
SELECT *
FROM Employee
WHERE Salary BETWEEN 25000 AND 33000;

Question 8: Write a query to display the names and salaries of employees whose salary is above 30,000 and whose gender is not male.
SELECT Name, Salary
FROM Employee
WHERE Salary > 30000
  AND Gender <> 'Male';

Question 9: Write a query to display the salaries of all employees.
SELECT Name, Salary
FROM Employee;

Question 10: Write a query to display the maximum salary of employees in each designation.
SELECT Designation, MAX(Salary) AS Maximum_Salary
FROM Employee
GROUP BY Designation;

Question 11: Write a query to display the name and respective department name of each employee whose salary is more than 30,000.
Assuming Employee.EMP_ID matches Department.EMP_ID, use:

SELECT E.Name, D.Dept_Name
FROM Employee E
JOIN Department D
    ON E.EMP_ID = D.EMP_ID
WHERE E.Salary > 30000;

Question 12: Write a query to display the employee name and designation from the Info table and department name and floor number from the Deptu table.
SELECT I.Name, I.Designation, D.Dept_Name, D.Floor_Number
FROM Info I
JOIN Deptu D
    ON I.EMP_ID = D.EMP_ID;

Question 13: Write a query to display the department name and sum of salaries, grouped by designation, from the Info and Deptu tables, in ascending order of the sum of salary.
SELECT D.Dept_Name, I.Designation, SUM(I.Salary) AS Total_Salary
FROM Info I
JOIN Deptu D
    ON I.EMP_ID = D.EMP_ID
GROUP BY D.Dept_Name, I.Designation
ORDER BY Total_Salary ASC;

Question 14: Write a query to display the number of employees in the Info table.
SELECT COUNT(*) AS Total_Employees
FROM Info;

Question 15: Write a query to display the maximum salary of male employees from the Info table.
SELECT MAX(Salary) AS Maximum_Salary
FROM Info
WHERE Gender = 'Male';
