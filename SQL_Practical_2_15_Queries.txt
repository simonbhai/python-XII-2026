# SQL Employee Table – Questions and Answers

## 1. Create the Employee Table

```sql
CREATE TABLE Employee (
    EMP_ID INT,
    Name VARCHAR(30),
    Gender VARCHAR(10),
    Age INT,
    Designation VARCHAR(30),
    DOJ DATE,
    Salary DECIMAL(10,2),
    City VARCHAR(30)
);
```

## 3. Fifteen SQL Questions and Answers

### Question 1: Display all employee records.

```sql
SELECT * FROM Employee;
```

### Question 2: Display employee names and salaries.

```sql
SELECT Name, Salary
FROM Employee;
```

### Question 3: Display employees whose salary is greater than 30000.

```sql
SELECT *
FROM Employee
WHERE Salary > 30000;
```

### Question 4: Display employees whose salary is less than 25000.

```sql
SELECT *
FROM Employee
WHERE Salary < 25000;
```

### Question 5: Display employees in ascending order of salary.

```sql
SELECT *
FROM Employee
ORDER BY Salary ASC;
```

### Question 6: Display employees in descending order of salary.

```sql
SELECT *
FROM Employee
ORDER BY Salary DESC;
```

### Question 7: Find the highest salary.

```sql
SELECT MAX(Salary) AS Highest_Salary
FROM Employee;
```

### Question 8: Find the lowest salary.

```sql
SELECT MIN(Salary) AS Lowest_Salary
FROM Employee;
```

### Question 9: Calculate the total salary of all employees.

```sql
SELECT SUM(Salary) AS Total_Salary
FROM Employee;
```

### Question 10: Calculate the average salary.

```sql
SELECT AVG(Salary) AS Average_Salary
FROM Employee;
```

### Question 11: Count the total number of employees.

```sql
SELECT COUNT(*) AS Total_Employees
FROM Employee;
```

### Question 12: Display employees whose names start with P.

```sql
SELECT *
FROM Employee
WHERE Name LIKE 'P%';
```

### Question 13: Display employees who joined after 1 January 1990.

```sql
SELECT *
FROM Employee
WHERE DOJ > '1990-01-01';
```

### Question 14: Display employees whose designation is NULL.

```sql
SELECT *
FROM Employee
WHERE Designation IS NULL;
```

### Question 15: Find the second-highest distinct salary.

```sql
SELECT MAX(Salary) AS Second_Highest_Salary
FROM Employee
WHERE Salary < (
    SELECT MAX(Salary)
    FROM Employee
);
```

## 4. Additional SQL Queries

### A. Add an Email column.

```sql
ALTER TABLE Employee

```

### B. Update Preeti's city to Kochi.

```sql
UPDATE Employee
SET City = 'Kochi'
WHERE Name = 'Preeti';
```

### C. Update Nisha's designation.

```sql
UPDATE Employee
SET Designation = 'Clerk'
WHERE Name = 'Nisha';
```

Note: Run this query only if the intended designation is Clerk. Otherwise, replace Clerk with the correct designation.

### D. Find employees with salaries between 20000 and 30000, inclusive.

```sql
SELECT *
FROM Employee
WHERE Salary BETWEEN 20000 AND 30000;
```

### E. Display unique cities, including NULL if present.

```sql
SELECT DISTINCT City
FROM Employee;
```

### F. Find employees whose names contain the letter a.

```sql
SELECT *
FROM Employee
WHERE Name LIKE '%a%';
```

### G. Increase every employee's salary by 10%.

```sql
UPDATE Employee
SET Salary = Salary * 1.10;
```

### H. Delete the employee whose ID is 7.

```sql
DELETE FROM Employee
WHERE EMP_ID = 7;
```

Warning: UPDATE and DELETE statements modify table data. Run them only when you intend to make those changes.

## 5. Useful Aggregate Queries

### Count employees in each city.

```sql
SELECT City, COUNT(*) AS Employee_Count
FROM Employee
GROUP BY City;
```

### Calculate the average salary in each city.

```sql
SELECT City, AVG(Salary) AS Average_Salary
FROM Employee
GROUP BY City;
```

### Display employees earning more than the average salary.

```sql
SELECT *
FROM Employee
WHERE Salary > (
    SELECT AVG(Salary)
    FROM Employee
);
```

### Find employees with a missing city.

```sql
SELECT *
FROM Employee
WHERE City IS NULL;
```

### Find employees with a missing designation.

```sql
SELECT *
FROM Employee
WHERE Designation IS NULL;
```
